# I’m Just Trying to Help

A web work by Roki Jongha Kim / Oxxy444.

Open `index.html` on **HTTPS** or `http://localhost` (needed for microphone and camera). From this folder:

```bash
python3 -m http.server 8765
```

Then visit `http://127.0.0.1:8765/`.

## GitHub Pages

Serve the repository root. Enable Pages on the `main` branch. The live site needs HTTPS so **listen** and **look** can request permissions.
